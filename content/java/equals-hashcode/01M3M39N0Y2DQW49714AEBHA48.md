重写 equals 的**五条军规**（违反任何一条，集合就会灵异）：

1. **自反**：自己跟自己必须相同；
2. **对称**：a==b 则 b==a——父类拿子类比出 true、子类拿父类比出 false（子类加了字段常见）→ ArrayList 里 contains 时灵时不应；
3. **传递**：a=b、b=c 则 a=c；
4. **一致**：字段没变，比多少次结果一样（别在 equals 里掺随机/时间）；
5. **非空**：跟 null 永远 false。

**术语速查**：对称=两边比必须同答｜传递=相等链不断裂｜混比=父子实例互比
