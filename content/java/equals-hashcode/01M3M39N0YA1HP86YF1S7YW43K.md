equals 的「一致」指：**参与比较的字段没变，答案就不能变**。掺进**时间、随机数、环境**这些外部状态，等于把「没修改字段」这个前提击穿：

- 两个对象此刻 equals true、下一秒 false；
- 上午放进 HashSet 的元素，下午 contains 找不到了——按入桶时的 hash 定位，按现在的状态比对，两头对不上。

**术语速查**：一致性=同输入同输出｜外部状态=不在对象字段里的世界变量｜过期失踪=入桶与比对口径漂移

<!--advanced-->
可变 key 的根本矛盾同源（hash 不变量）。测试建议：多次调用 equals 结果应恒定；反射注入验证不掺随机。JLS/集合框架注释明确以「info not modified」为一致性前提。
