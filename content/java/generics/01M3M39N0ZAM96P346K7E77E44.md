**PECS 口诀**（Producer-Extends, Consumer-Super）——把集合当成对手方：

- **`? extends T`（它是生产者，给你数据）**：**只读**。`List<? extends Number>` 可能背后是 `List<Integer>`——你 add 进去的 Double 对它就是异物。读出来统一按 Number 收货。
- **`? super T`（它是消费者，吃你的数据）**：**只写**。`List<? super Integer>` 背后可能是 `List<Number>`——写 Integer 没毛病（Integer 一定是 Number）；读出来只能当 Object。

一句话：**extends 读、super 写**；不确定时用精确类型。

**术语速查**：生产者=给你读的来源｜消费者=收你写的去处｜PECS=选通配符的口诀

<!--advanced-->
Java 数组协变是反面教材（运行时 ArrayStoreException）；泛型不协变故需通配符。Collections.copy(src ? extends T, dest ? super T) 是 PECS 教科书签名。`<?>` 即 `? extends Object`。
