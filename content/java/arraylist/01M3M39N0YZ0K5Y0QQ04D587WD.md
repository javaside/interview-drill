`Arrays.asList(arr)` 返回的是披着 List 外皮的**原数组的定长视图**：

- **set(i, x)**：✅ 可以——而且改的就是**原数组**那个位置（它俩共享数据）；
- **add / remove**：❌ 炸 `UnsupportedOperationException`——长度锁死（内部没有扩容机制）。

要真正的可变列表：`new ArrayList<>(Arrays.asList(arr))`（拷贝一份）。`List.of(...)` 更狠：连 set 都不许（完全不可变），但元素非 null。

**术语速查**：定长视图=能看能改不能变长｜写回原数组=视图与数组同内存

<!--advanced-->
ArrayList(E[]) 单参内部构造直接引用数组（asList 即此），不拷贝；基本类型数组的坑：asList(int[]) 得到 List<int[]>（长度 1）——装箱只对引用类型数组发生。List.of 基于内部不可变实现，null 元素立即 NPE。
