ArrayList 底层是个 `Object[]`，满了就得**换更大的房子搬家**：

1. `new ArrayList()`：内部先是个**空数组**（不占内存）；第一次 `add` 扩到 **10**；
2. 之后每次放不下：新容量 = 旧的 **1.5 倍**（`oldCap + (oldCap >> 1)`）；
3. 搬家 = 新建数组 + **整体拷贝**旧元素（`Arrays.copyOf`）——这是扩容的 O(n) 代价。

所以**能预估就传初始容量** `new ArrayList<>(10000)`——一次到位，免去一路 10→15→22→…的反复搬家。

**术语速查**：扩容=换更大的数组搬家｜1.5 倍=新容量公式｜均摊=偶尔贵、平均便宜

1.5 折中空间浪费与再扩频率（2 倍的渐进浪费 4n vs 2.25n）。grow 上限 MAX_ARRAY_SIZE=Integer.MAX_VALUE-8，超限 OutOfMemory。elementData 用 transient，序列化走 writeObject 只写 size 内元素（避免序列化尾部空槽）。
