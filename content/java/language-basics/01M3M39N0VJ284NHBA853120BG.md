**==**：基本类型（int/double…）比**值**；引用类型（对象）比**是不是同一个**（内存地址）。

**equals**：Object 的默认实现就是 `==`——但类可以**重写**它来定义「内容相同算相同」。String、Integer 这些都重写了：两个内容一样的字符串，`==` 是 false（两个对象），`equals` 是 true（内容一样）。

铁律：**重写 equals 必须同时重写 hashCode**，否则 HashMap/HashSet 里会出灵异事件（详见 equals-hashcode 块）。

**术语速查**：==比值或比地址｜equals=内容相同（可重写）｜重写=子类换掉父类方法实现

<!--advanced-->
== 对引用比较引用恒等（identity）；equals 语义由类自定（逻辑等值）。Object.equals 即 ==；jdk 类按值语义重写。规范要求 equals 满足自反/对称/传递/一致/null 为 false 五性质，并与 hashCode 协同：equals 相同 ⇒ hashCode 必相同，反之不必。
