Java **只有值传递**——传的永远是**副本**：

- **基本类型**：复制值本身。方法内改副本，外面毫无感觉。
- **对象**：复制的是「**地址值**」。方法内拿到的副本地址指向**同一个**对象——通过它改对象的**字段**，方法外的变量会**跟着变**（调用方（caller）能看到这次修改，因为从头到尾就这一个对象）；但让这个参数**指向新对象**（重新赋值），改的只是副本地址，外面的变量纹丝不动。

经典反证：你写不出一个能交换两个 int 的 swap 方法——因为方法内拿到的是副本。

**术语速查**：值传递=传副本｜地址值=引用里存的对象位置｜重新赋值=只换了副本的指向｜调用方=发起这次调用的一方（caller）

<!--advanced-->
JLS 规定参数传递按值（pass-by-value），对象引用本身按值复制。C++ 的引用传递（alias）在 Java 不存在。mutable 参数的字段修改可见性源于共享堆对象，而非传递语义。
