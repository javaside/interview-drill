HTTPS = **HTTP 穿上 TLS 的装甲**。握手要办两件事：**验明对方身份**（证书）+ **商量出对称密钥**（之后加密数据用）：

```
C → ClientHello（TLS 版本、套件列表、随机数 C）        打招呼报菜名
S → ServerHello（选定套件、随机数 S）+ 证书链           点菜+亮证件
C → 验证证书链 → 用证书公钥加密「预主密钥」发去          验证件+递钥匙坯
双方 → (C随机数 + S随机数 + 预主密钥) 导出会话密钥
C/S → 互发 Finished（用会话密钥加密的验证串）           握手成功
```

**三个素材缺一不可的原因**：预主密钥可能被穷举、随机数可能被预测——**三份熵**凑一起才让会话密钥不可猜。**Finished 消息**是握手的自检：把之前全部握手报文做摘要加密互验，防中间人**篡改握手内容**（比如偷偷把套件降级到弱加密——降级攻击）。

**术语速查**：证书=身份的公证处背书｜预主密钥=钥匙坯｜Finished=握手的防篡改封条
