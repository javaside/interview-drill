两种节奏：**即兴演员 vs 先列提纲的导演**。

| | ReAct（边走边看） | Plan-and-Execute（先谋后动） |
|---|---|---|
| 节奏 | 每步观察后即兴决定下一步 | 先产出**完整计划**，再逐项执行 |
| 强项 | 简单/探索性任务，适应力强 | **长任务**：步骤不迷路、计划可审计可并行 |
| 弱点 | 长链条累积漂移——「为什么走到这」自己都忘了 | 计划赶不上变化——中途世界变了计划作废 |
| 成本 | 每步都要大模型判断 | 计划一次贵模型、执行可小模型（分级） |

**长任务 ReAct 迷路的机制**：十几轮观察后，最初目标在上下文里被稀释，模型开始「为走而走」——每步局部合理，整体跑偏。**Plan-and-Execute 的解法**：计划是**显式清单**钉在上下文里，每完成一项打勾——进度可见、可断点续跑、可人工审计。

**生产的常见组合**：先 Plan 生成步骤清单 → 每个步骤内部用 ReAct 执行 → 执行结果与计划**偏差超阈值**（工具报错/结果与预期差太远）触发**重规划**。

**术语速查**：即兴 vs 提纲=两种节奏|计划钉上下文=长任务不迷路的锚|分级执行=计划用大模型执行用小模型
