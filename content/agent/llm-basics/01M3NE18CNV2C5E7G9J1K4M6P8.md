**结论：不能彻底消除——它是生成式范式的结构性产物，只能压低到业务可接受的水平。**

三层根源，一层比一层不可绕：

1. **训练目标错位**：下一 token 预测优化的是「**像人话**」不是「**是真的**」——「文献显示该比例约为 37%」这个句式太像真话了，模型补得出句式补不出事实；
2. **参数=有损压缩**：几万亿 token 压进几千亿参数，教科书级事实记得住，长尾细节（某库某版本某参数）必然糊——糊的地方模型不会留白，会**流畅地编**；
3. **自回归不回头**：一旦开头断言错了，后续 token 都以「刚才说的是对的」为前提生成——圆谎比认错更「像人话」。

**工程化缓解组合拳**：RAG（给依据，让它抄别让它默）｜明确许可说不知道（prompt 授权 + 抽象层拒绝路径）｜引用溯源（每个断言挂来源，无源即警示）｜事后校验（规则/二次模型核对关键数字）。**业务红线设计**：医疗/法律/金融场景，幻觉率是核心验收指标，用评测集持续回归。

**术语速查**：流畅≠真实=训练目标的裂缝|有损压缩=细节必然糊|圆谎机制=自回归的惯性
