Token 是 LLM 应用最大的变动成本，控制是**层层杠杆**的叠加：

1. **模型分级（最大杠杆）**：80% 的请求是分类/抽取/改写——小模型十分之一价格足够好；先小后大（小模型拿不准再升级）或路由分类器分流。**别用大炮打蚊子，也别让蚊子挡住需要大炮的**；
2. **缓存**：**prompt 前缀缓存**（system+文档头部不变——命中部分按折扣计费，把不变的放头部是纪律）；**语义缓存**（相似问题命中历史答案——要小心时效性问题的误命中）；
3. **上下文瘦身**：长对话摘要压缩（十轮变一段）、工具的大段输出用完替换成结论（「上一步查询返回 12 条」替代 50 行 JSON）——**省输入 token 就是省最多的钱**（输入占大头）；
4. **批处理**：离线评测/批量打标走 batch API（约五折，换小时级延迟）；
5. **护栏**：按用户/功能的用量监控、预算告警、单请求 token 上限——**循环里的 Agent 一旦疯跑，一夜烧掉一个月预算**是真实事故。

**术语速查**：模型分级=最大的一级杠杆|前缀不变=缓存命中的纪律|护栏=失控当天的止损线

成本可观测（每请求记录 input/output/cache token 与折算金额——按功能维度出账）。蒸馏（高频任务微调小模型替代）。结构化输出的 token 节省（比自由文本答案短且可机读）。
