隐私的第一问不是「加密了吗」，而是**「数据流向图」**：用户输入 → 模型供应商（留不保留？训不训练？）→ 日志系统（存多久？谁能看？）→ 评测集（真实数据混进去了吗？）——每一跳都要有答案。

**分档处理**：

- **红线数据**（金融交易/医疗记录/法务文件）：数据不出域——**专有云或本地部署**（企业级 API 的零保留条款）或开源模型内网跑；检索库、向量库全在域内；
- **一般数据**：API 前过 **PII 脱敏**（手机号/身份证/卡号替换成占位符——答案回来再还原映射）；确认供应商的**数据用途条款**（是否用于训练、保留窗口、能否签 DPA）；
- **最易忽视的泄漏口是日志**：排查问题时把 prompt 全文打进日志——等于把用户数据复制了一份且权限更松。**日志分级**：默认脱敏摘要（长度/哈希/标签），完整样本单独加密存储、按需开箱、限期销毁；
- **评测集也是数据**：用真实坏例建评测集时先脱敏——「测试便利」不该成为二次泄漏的理由。

**内网部署 ≠ 自动安全**：模型服务器本身（无鉴权的 Ollallama/vLLM 端口）、内网日志、备份数据库都是新的泄漏面——隐私是流向管理，不是部署位置。

**术语速查**：数据流向图=每一跳都要有答案|零保留条款=企业级 API 的关键行|日志=最松的泄漏口

PII 还原映射表的安全等级（映射表本身就是敏感数据——独立加密）。跨境数据合规（数据出境评估——中国 PIPL/欧盟 GDPR 双框架）。向量库的隐私（embedding 可被反演近似还原——向量也是数据）。
