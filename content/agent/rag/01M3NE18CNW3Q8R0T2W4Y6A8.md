两条检索路线的**感知方式**不同，盲区恰好互补：

| | 向量检索 | 全文检索（BM25/关键词） |
|---|---|---|
| 原理 | 语义压缩成向量比距离 | 词面精确匹配+词频权重 |
| 强项 | 同义改写、跨表述、模糊意图（「退货政策」↔「退款流程」） | **精确保留串**：型号 SX-200、错误码 E4001、函数名、人名 |
| 盲区 | 记不住精确 token（把 E4001 检索成 E4002 的近邻） | 不懂同义（问「退货」没收录该词就全空） |

**生产默认是混合**：向量+全文两路并发，**RRF（倒数排名融合）**把两路的排名合并——不比分数只比名次（分数不可比，名次可比），两路都靠前的块胜出。用户问「E4001 怎么处理」时：全文路精确命中错误码，向量路兜住「怎么处理」的语义——单路必丢一半。

**再叠一层过滤**：权限（这个用户只能看本部门文档）、时效（只要今年版本）——**元数据先收敛候选集，再做相似度排序**——既快又安全（权限过滤放检索后是越权漏洞）。

**术语速查**：语义 vs 词面=两种感知|RRF=只比名次不比分数|先过滤后排序=安全又快
