长对话的核心认知：**上下文窗口是有限预算，管理它就像管理内存**——历史无限涨，预算就爆（截断、贵、注意力稀释三连）。四板斧：

- **滑动窗口**：最近 N 轮原文保留（对话连贯靠近期上下文），超出的部分**摘要压缩**——「用户在问订单 12345 的退款，已完成身份验证」一句顶十轮。摘要要点：保留**事实与决定**（编号/偏好/结论），丢掉寒暄与重复；
- **长期记忆外置**：跨会话要记住的（用户称呼、项目背景、既有约定）**写进数据库**，下次会话检索注入——这就是「记忆即 RAG」：记忆系统本质是对「过去对话的检索增强」，向量库存记忆条目，按当前话题召回；
- **工具产物清理**：中间步骤的大段工具输出（上一步的 50 行 JSON）用完即弃或换结论——它们挤预算但不增信息；
- **主动遗忘**：跑题的旧内容、已完成的分支，删除反而提升质量——无关 token 会稀释注意力，**记得少有时答得好**。

**术语速查**：预算=窗口当内存管|近原文远摘要=分层存储|记忆即 RAG=过去对话的检索
