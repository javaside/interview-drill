**让模型输出可靠 JSON 的正路是约束解码，不是求它**：

1. **原生结构化输出**（首选）：`response_format`/`structured output` 把 JSON Schema 直接喂给推理层——**采样被语法约束**，非法 token 根本不会被选到，格式正确率接近 100%；
2. **工具调用通道**（Agent 场景）：把「输出」定义为工具的 `input` 参数——参数本身按 schema 校验生成，还顺带拿到「模型决定调用」的语义；
3. **辅助手段**：temperature 0-0.2 + 一两个完整示例（few-shot 传格式比描述格式可靠）。

**自由文本求 JSON 是反模式**：模型会用 Markdown 围栏裹、字符串里带未转义引号、偶尔加一句「好的，以下是」——每个都是解析炸弹。

**防御三件套**（即使有原生能力也要）：try-catch 重试（带错误信息回喂）、宽松解析（剥围栏/尾逗号）、**jsonschema 校验通过才进业务**——校验失败的字段走降级路径，别把模型输出直接当可信数据。

**术语速查**：约束解码=非法 token 选不到|schema 即契约=结构靠定义不靠描述|校验后才用=永远不当真
