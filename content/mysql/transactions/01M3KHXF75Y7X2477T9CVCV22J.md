MySQL 默认**自动提交**：你写一条 `update`，它自己就是一个小事务，执行完立即提交。想把多条语句打包成一个「全做或全不做」的事务，要显式声明：

```sql
BEGIN;          -- 或 START TRANSACTION
UPDATE ...;
UPDATE ...;
COMMIT;         -- 全部生效；想全撤销用 ROLLBACK
```

**术语速查**：autocommit=每条语句自动成事务提交｜显式事务=begin 到 commit 之间的一段

<!--advanced-->
autocommit=0 时会话进入隐式事务模式（ equivalent 于持续开启的显式事务）。DDL、隐式提交语句（ALTER/CREATE/DROP 等）会先提交当前事务再执行。commit 即触发持久化与 binlog 落盘（受 sync_binlog 影响）。
