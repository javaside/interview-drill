一次被切面套住的方法调用，**洋葱圈**顺序（外到内再出来）：

```
@Around 前段 → @Before → 【目标方法】 
   正常：→ @AfterReturning → @After → @Around 后段
   抛错：→ @AfterThrowing → @After → 异常继续外抛（除非 Around 接住）
```

要点：**@After 是 finally 语义**（无论成败必跑）；**Returning 和 Throwing 互斥**（二选一）；@Around 最外层——`proceed()` 一刀分开前后段，还能**吞异常/换返回值**（慎用）。

**术语速查**：洋葱圈=层层包住｜proceed=放行进内层｜After=finally 语义

<!--advanced-->
多切面 @Order 值小者外层（链首）；链整体是 MethodInterceptor 的递归栈。AfterThrowing 不吞异常（只观察）；Around 捕获异常会阻断外层 Throwing。5.2.7 起 AspectJ 语义统一入序出序。
