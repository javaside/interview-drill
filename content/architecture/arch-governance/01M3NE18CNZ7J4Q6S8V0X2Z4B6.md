数据迁移的铁律：**每一步都可回滚，任何时刻都有「谁是权威数据源」的明确答案**。标准五步：

```
①双写上线（老库为准）：写老库成功才写新库，新库写失败只告警不阻断
②存量搬迁：全量导老数据 → 批量导入新库 → 停写窗口补增量
   校验三件套：总条数 / 随机抽样逐字段 / 按主键分块的校验和
③灰度切读：1% 流量读新库，与老库结果双读 diff
   不一致 → 立即回切 + 排查（这一步只读，回滚零风险——所以难点全在这一步暴露）
④切写（最险）：写主切新库，新库为准，反向双写老库（留退路）
   观察至少一个完整业务周期（周结/月结跑完）
⑤摘旧：停双写 → 旧库转只读归档（保留 N 周回滚窗口）→ 退役
```

**最容易翻车的是②→③之间**：存量与增量的衔接缝（批量搬完到切读之间的新写入漏没漏）——用**变更时间水印 + 校验和复验**兜底。**双写不一致的处理**：以权威库为准**修新库**，同时记录不一致样本找根因（异步补写失败？事务边界？时区？）——**绝不能各改各的**。

**术语速查**：权威数据源=每一步都要答的问题|双读对账=切读的安全绳|反向双写=切写后的退路
